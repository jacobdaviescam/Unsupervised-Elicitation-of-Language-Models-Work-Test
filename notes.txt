Algorithm:
Parameters: K, N, T0, Tmin, beta

Load the train dataset as your unlabeled dataset (only questions and answers (examples))

Initalise D (labeled dataset) as empty set - to be filled in 

Randomly select and label K examples - update D

for n to N:
    Update temperature
        T <- max(Tmin, T0/1+beta(log(n)))

    Sample example from unlabeled dataset (question-answer pairs)
    
    Assign label
        yhati = argmax(Ptheta(yi|xi, D \ ({xi, yi})))
    
    Temporarily update
        Dhat = D U ({xi, yhati})

    delta = U(Dhat) - U(D)
    
    if delta > 0:
        D = Dhat
    else:
        if random(0, 1) < exp(delta/T):
            D = Dhat
